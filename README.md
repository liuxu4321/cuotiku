# 拾星错题本（yycuotiku · Electron 桌面版）

把错题照片快速整理为一张可打印的 A4 图片。新版本基于 Electron 43、Vue 3、TypeScript 和 Sharp。

## 功能

### 菜单命名对照（防歧义）

| 菜单名 | 原功能 | 说明 |
| --- | --- | --- |
| 反躬自省 | 首页 | 个人能力模型：五维雷达图与明细 |
| 集腋成裘 | 错题收集 | 工作台：导入、切边增强、框选错题、去手写、加入错题集 |
| 千锤百炼 | 举一反三 + 错题精讲（合并） | 单选一道错题：知识精讲（文本）或举一反三（专用 B5 模板，每页两题，输出三道同类变式题） |
| 温故知新 | 错题组卷 | 错题集筛选、随机抽题、模板组卷与打印 |
| 关于 | 关于 | 版本、更新、知识星球入口 |

- 多图导入、高拍仪导入（UVC 摄像头采集，Windows/macOS）、图片拖拽、滚轮缩放和适合窗口
- 「切边增强」按钮（会员 AI 权益）：批量优化已导入图片（切边/矫正/增强），处理中全屏加载遮罩
- 左右 90° 旋转及 -45°～+45° 微调旋转
- 连续框选错题，支持移动选框和八方向调整大小
- 预览与框选实时同步
- 记录年级、学期（上/下）与科目（语文/数学/英语），错题可一键加入错题集回顾
- 年级与学期全局统一：首页/集腋成裘/千锤百炼/温故知新共用同一选择，任一处调整即时同步并持久化到配置（重启不丢失）；年级范围 1-12
- 随机抽题组卷调用服务端公平算法（最少练习优先、同层随机、全覆盖轮转），按科目/学期/错误类型筛选
- 错题集以本地目录存储（图片 + SQLite 数据库 cuotiku.db，默认 home 目录隐藏文件夹 `.cuotiku`，可在设置中修改），左右分栏：左侧筛选/多选错题，右侧组卷打印区自动同步排版（默认 A4、自动换页）并直接打印
- 「去手写」按钮（会员 AI 权益）：对已导入原图逐张调用后台手写擦除并替换源图，与选框无关，处理中全屏加载遮罩
- 自动、单列或双列排版，错题尽量保持原尺寸、靠左排列并自动换页，300 DPI 保存和系统打印
- 三种打印方式：普通纸（A4/B5 多列排版）、热敏纸（常用尺寸、每题一页、左上对齐）、模板打印（内置 8 个模板：A4/B5 各 1-4 卡错题本版式，设置页可预览选择）
- 集腋成裘页「排版与模板」按钮弹出模板缩略图面板（A4 一行、B5 一行，缩略图为卡片版式示意），点击即切换模板并自动切到模板打印模式；当前已有错题框选时立即重排预览
- 排版、图像增强、账号与服务器、外观设置
- AI 去手写与组卷打印需登录授权（知识星球会员开通）；未登录使用 AI 去手写弹出登录框（强制登录）
- 半强制登录：加入错题集、保存图片、打印等未登录时仅弹出知识星球引导与会员权益介绍（不显示登录框）
- 双令牌会话：访问令牌 2 小时 + 刷新令牌 30 天（safeStorage 加密保存）；401 时静默刷新并重放一次请求，刷新令牌轮换更新；4011 被踢即清会话并提示
- 修改密码（设置 → 账号）：`POST /api/auth/password` 自助修改（校验原密码、新密码 6-64 位且不同于原密码），成功后双令牌立即失效，自动登出并提示用新密码重新登录
- 客户端心跳（Keepalive）：每 60 秒上报 `POST /api/client/keepalive`（clientId 持久化 UUID、版本、平台、状态），登录态自动附带令牌，失败静默重试
- 千锤百炼（举一反三 + 错题精讲合并）：单选一道错题，调用 `POST /api/agent/explain`（文本框展示精讲）或 `POST /api/agent/analogy`（专用 B5 举一反三模板，每页两题排版题干/选项/答案/解析，可打印）；需登录且开通 AI 权限，调用期间心跳状态置 busy，超时 150s

## 开发

需要 Node.js 22、Corepack 和 pnpm 11。

```bash
pnpm install
pnpm dev
```

质量检查与打包：

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm package
```

## 配置文件

应用启动时按顺序读取 `yycuotiku.config.json`（可执行文件目录 → 用户数据目录 → 工作目录），示例：

```json
{
  "serverUrl": "http://127.0.0.1:8080",
  "planetUrl": ""
}
```

- `serverUrl`：后台服务地址（必填，http/https）。
- `planetUrl`：知识星球链接，登录对话框引流按钮使用。
- 修改后重启应用生效；设置页「账号」分区只读展示当前生效值与配置文件路径。

## 发布与自动升级

- 修改 `package.json` 版本号并提交；打标签推送触发 GitHub Actions：`git tag v1.0.0 && git push origin v1.0.0`。
- `.github/workflows/release.yml` 在 windows-latest 上构建 NSIS 安装包（含自动升级元数据 `latest.yml`）；标签带 `-beta` 等后缀时走 beta 通道。
- 自动升级源为腾讯云 COS（`electron-builder.yml` 中 `publish.provider: generic`，地址 `https://generic-1257458058.cos.ap-guangzhou.myqcloud.com/yycuotiku`）：CI 用 `coscmd` 上传安装包、`.blockmap` 与 `latest.yml`（清单设 `Cache-Control: no-cache`），客户端 electron-updater 从该地址检查与下载，规避国内访问 GitHub 的问题。同时仍发布 GitHub Release 作为归档。COS 密钥通过仓库 Secrets `COS_SECRET_ID` / `COS_SECRET_KEY` 注入。
- 应用内置 electron-updater（Windows/macOS）：启动 15 秒后检查，并每 4 小时复查；也可从「帮助」菜单、「关于」页或「设置 → 高级」手动操作。
- 「帮助」菜单会随更新状态切换为检查、下载、下载进度或重启安装；设置中可选择稳定版/测试版通道。下载完成后始终由用户确认重启，不会强制中断当前工作。

## 架构

- `src/renderer`：Vue 工作台、Canvas 交互、Pinia 状态和设置页
- `src/preload`：窄接口 `window.desktopAPI`
- `src/shared`：IPC 通道、Zod 校验和共享类型
- `src/main`：本地文件、Sharp 高清处理、后台接口客户端、保存与打印

渲染进程不直接访问 Node.js、Electron、文件路径或应用密钥。图片原路径和后台请求均保留在主进程，登录 token 使用系统安全存储加密保存。

后台接口文档：`yycuotiku-server/docs/API.md`（客户端仅按文档对接，不修改）。
